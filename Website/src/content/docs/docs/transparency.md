## How Eskele was built

**Eskele's code was written with the help of AI.** Much of the Swift source, the tests, the build
scripts and this documentation was drafted with an AI coding assistant, then directed, reviewed and
shaped by a person.

**Testing the app itself was done by a human.** The automated test suite checks the logic, but how the
bar actually looks and behaves — on each edge, on several displays, with real apps, permissions and
settings — was tried by hand on a real Mac.

That is said here so you can weigh it for yourself. The full source is
[on GitHub](https://github.com/hossainalhaidari/eskele), and anything that looks wrong is welcome as
an [issue](https://github.com/hossainalhaidari/eskele/issues).
